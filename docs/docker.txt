Exact Commands to Demo the Infra Bundle

// bash
# 1. Build & start both services (app + PostgreSQL 15)
docker compose up --build
use docker compose up --build for normal development. 
Use 
docker compose build --no-cache app
 when you specifically need a fresh rebuild of the application image.
 
# 2. Verify health
curl -i http://localhost:8000/health          # 200 JSON
curl -I http://localhost:8000/health           # 200 HEAD
 
# 3. Log in with built-in demo credentials
curl -s -X POST http://localhost:8000/api/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin2026"}'
 
# 4. Run Locust load test (authentic scenario only, avoids the Quantum Circuit Breaker)
locust -f locustfile.py --headless -u 10 -r 2 --run-time 30s --host http://localhost:8000
